# Welcome to the official repository for the manuscript "Longitudinal Machine Learning and snRNA-Seq Reveal Stroke-Specific Behavioral and Transcriptional Signatures".

This project integrates longitudinal machine learning (ML) behavioral profiling with single-nucleus RNA sequencing (snRNA-seq) to decode the multi-dimensional trajectories of stroke recovery and identify cell-type-specific molecular signatures.
